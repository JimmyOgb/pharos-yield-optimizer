## 2. Rule-by-Rule Technical Justification

| Rule Entry | Target Category | Rationale & Security Justification |
| :--- | :--- | :--- |
| `node_modules/` | Dependencies | Third-party packages should never be committed to Git; cleanly installed via `npm install`. |
| `dist/` | Build Output | Compiled ESM bundles (`dist/server.js`, `dist/api/*.js`, etc.) are 100% reproducible via `npm run build`. Excluding them prevents Git bloat and merge conflicts. |
| `build/`, `*.tsbuildinfo` | Compiler Caches | Incremental TypeScript compiler cache artifacts. |
| `.vercel`, `.vercel/`, `.vercel_build_output/` | Platform Caches | Local Vercel project linking IDs, deployment tokens, and builder caches. Excluded to prevent leaking local environment metadata. |
| `.env`, `.env.local`, `.env.*.local` | Private Overrides | Prevents accidental commitment of local developer secrets or RPC overrides. `.env.example` is explicitly NOT ignored. |
| `*.pem`, `*.key` | TLS / Key Files | Defense-in-depth prevention against committing certificates or private key files. |
| `Thumbs.db`, `.DS_Store`, `Desktop.ini` | OS Artifacts | Windows and macOS filesystem metadata files. |
| `.vscode/`, `.idea/` | IDE Configs | Developer-specific IDE workspace settings. |
| `*.log`, `npm-debug.log*` | Logs | Local runtime logs and npm execution debugging traces. |
| `coverage/`, `.nyc_output/` | Test Artifacts | Temporary code coverage reports generated by `npm run test:coverage`. |
